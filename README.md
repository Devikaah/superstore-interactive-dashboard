Superstore Interactive Sales Dashboard

An interactive, responsive dashboard built to explore and analyze Superstore sales data. The project brings key business metrics, visualizations, and detailed records together in one place.

## Features

- **KPI Cards:** Monitor sales, profit, orders, and profit margin.
- **Interactive Filters:** Explore performance by year, region, category, segment, and shipping mode.
- **Data Visualizations:** Analyze sales trends, category contributions, regional performance, and subcategory results.
- **Order Details:** Search and navigate detailed order records.
- **Returns Analysis:** Explore returned-order information.
- **Regional Managers:** View regional management details.
- **CSV Export:** Export data for further analysis.
- **Responsive Design:** Use the dashboard on desktop and mobile screens.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- SVG Data Visualizations
- CSV Export

## How to Run

1. Download or clone this repository.
2. Open `superstore_interactive_dashboard.html` in a web browser.
3. Use the filters and interactive charts to explore the data.

No separate installation is required.

## Project Objective

The objective of this project is to present business data in an accessible, interactive format and demonstrate practical skills in data visualization, dashboard design, and exploratory data analysis.
